Microsoft Build Tools 2013 does NOT contain the v120_xp toolset needed to compile this project!

You will need to obtain the toolset by mounting en_visual_studio_community_2013_with_update_5_x86_dvd_6816332.iso
and running vs_community.exe to set it up. Compile with a later version of visual studio if trial period is over.

Download Visual Studio: https://visualstudio.microsoft.com/vs/older-downloads/
You could also use a later toolset other than v120_xp but there could be problems (not tested).
