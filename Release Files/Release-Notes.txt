Release Changes V26 and onward:
V26 Release - Initial
V26 Release 1.01 - Fixed ROM browser regression
V26 Release 1.02 - Fixed Glide64 regression with fullscreen reset, cleared Glide64 configs autocreated by the plugin, removed settings window on bootup for GLideN64/LLE, updated 2 plugin notes, added experimental ANGLE GLideN64 fork for PJ64-based SM64 hacks to additional plugins zip, updated release notes with source links and release changes.
V26 Release 1.03 - A large number of minor things added/removed/tweaked that don't deserve any special mentioning. Notably Direct64 and Glide64 are now removed (if your PC does not support GLideN64, you should just upgrade to one that does because Direct64/Glide64 are way too buggy for regular usage).

*This release should obsolete all previous (published before this date, 10-21-2026) releases of Project64 in terms of plugin, database, retail game, and ROMhack support for Windows PCs. So if you have any previous release of Project64 installed on your PC, I suggest migrating to this one.

To set this up, you'll need to download the current BruceIV-Project64-1.6.2 zip file to obtain a copy of the emulator package for your Windows PC. After extracting the folder inside, you can begin playing retail and ROMhacked N64 games right away. There is no installation process. If you ever get a prompt to install my Project64 1.6.2, be wary of malware. My Project64 1.6.2 is released as PORTABLE ONLY!

If desiring to patch ROMhacks, you'll need to use the Tool64 app in the Apps folder to convert baseROMs to big endian .z64 if they aren't already, then you can either use flips.exe to apply a patch for a single ROMhack, or use the FlipsAutoPatcher-v2.1.1.exe for patching multiple ROMhacks at a time. ROMhacks can be obtained from https://github.com/BruceShankleIV/Project64-1.6.2-ROMhacks-Collection

If intending to make a translation for the emulator, a sample has been provided to work off of.

If intending to play multiplayer online instead of locally, an option to do that via the netplay input plugin is provided in the Additional-Plugins.zip file. Source: https://www.play64.com/netplay-plugin/

Also included in the Additional-Plugins.zip file is support for raphnet N64 to USB adapters (versions 3 and up) to allow use of an N64 controller with Project64 using raphnetraw plugins. If you have an adaptoid then you can use the N-Rage plugin already included with the emulator package. Source: https://www.raphnet.net/programmation/mupen64plus-input-raphnetraw/index_en.php#5

A fork of GLideN64 which supports SM64 hacks made for Project64 is included in the Additional-Plugins.zip file with ANGLE-SM64Hacks.dll. Should theoretically allow proper native widescreen support for SM64 hacks targeting PJ64 emulators. May have slight texture flickering issues. May have display issues with missing pixels when the status bar doesn't get created and when refreshing between windowed resolutions, and should not ever be used with framebuffer enabled under any circumstances. This plugin could be prone to errors, same for the previous 2 plugins described (not tested due to lack of time). Source: https://github.com/Luna-Project64/GLideN64/releases

Lastly, Direct64 and Glide64 are included in the Additional-Plugins.zip file. These are very old plugins which perform very poorly. There is little reason to use them, but they can be useful to play modern ROMhacks if GLideN64 does not work on your PC. Just don't enter fullscreen when using either of these plugins because they are very buggy! Examples of modern ROMhacks you can play with these: Ultimate Trial and Pumkin Tower.
